# 👋 Oi, eu sou a Gabriela!

Apaixonada por tecnologia desde cedo, encontrei na **Qualidade de Software** o espaço ideal para unir curiosidade, análise e impacto real no produto.

Tenho **4 anos de experiência** na área, com uma trajetória que passou por estágio, QA Júnior e Pleno, até chegar ao papel de **QA Lead**.
